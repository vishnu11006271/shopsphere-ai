# ShopSphere AI

A frontend-first shopping platform built with Next.js, React, TypeScript, Tailwind CSS, Zustand, and TanStack Query.

## Project status

Initial project foundation. See `docs/ARCHITECTURE.md` for architecture decisions and the implementation roadmap.

## Getting started

```bash
npm install
cp .env.example .env.local
npm run dev
```

The initial scaffold is being developed on `feature/project-setup` before review into `main`.
